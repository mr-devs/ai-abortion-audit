# Generate Tables

This directory contains scripts for generating formatted results tables (e.g., LaTeX, CSV, or other table formats) for publication or reporting purposes.
Scripts transform processed analysis results into publication-ready tables.

## Contents

- [`summarize_pilot_results.py`](summarize_pilot_results.py): Summarizes the pilot-4cities results into small CSV tables (what the chatbots recommend, where those places are, what answers say about state law, which websites readers see) in [`results/tables/pilot_results/`](../../results/tables/pilot_results/); these feed the pilot results dashboard.
