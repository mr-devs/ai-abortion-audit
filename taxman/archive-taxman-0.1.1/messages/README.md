# Messages (taxman 0.1.1)

The first pilot's message files, one message per line. taxman 0.1.1 numbered messages by position (`m0000`, `m0001`, ...), so the same question has the same id in all three files.

## Contents

- [`pilot-queries.txt`](pilot-queries.txt): The ten general questions, with no location.
- [`pilot-queries-houston-tx.txt`](pilot-queries-houston-tx.txt): The same questions about Houston, TX.
- [`pilot-queries-portland-or.txt`](pilot-queries-portland-or.txt): The same questions about Portland, OR.
